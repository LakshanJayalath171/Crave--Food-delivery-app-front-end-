🍔 Crave — Food Delivery Application

Crave is a modern food delivery application designed to make discovering, exploring, and ordering food simple and convenient. Built with React, NestJS, and MongoDB, the project aims to deliver a seamless food ordering experience through a responsive user interface and a modular backend architecture.

🛠️ Tech Stack

Technology                           Purpose

React                                Frontend user interface
NestJS                               Backend framework
TypeScript                           Type-safe backend development
Node.js                              JavaScript runtime
MongoDB                              NoSQL database
Mongoose                             MongoDB object modeling
JWT                                  Token-based authentication
bcryptjs                             Password hashing
Cloudinary                           Image storage and management
Tailwind CSS                         Frontend styling
